# SER FELIZ – App de plan alimenticio personalizado

Proyecto individual de la materia Tópicos Avanzados de Programación
Instituto Tecnológico de Jiquilpan – Ingeniería en Sistemas Computacionales

## Descripción
Aplicación móvil en la que un nutriólogo puede personalizar un plan
alimenticio para el usuario, según su edad, peso, estatura, objetivo
y preferencias de alimentos.

## Funciones planeadas
- Registro de usuario y perfil
- Encuesta de preferencias de alimentos
- Seguimiento de calorías, proteínas, grasas y carbohidratos
- Recordatorios de comidas (desayuno, comida, cena, etc.)
